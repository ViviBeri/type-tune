# Security Policy

## Supported Versions

Security fixes are handled on the latest released version of type-tune.

The npm package is a launcher for platform-specific Rust binaries. Please include the operating
system, architecture, package versions, and any checksum error when reporting an installation or
launcher integrity issue.

## Reporting a Vulnerability

Please do not open a public issue for a security vulnerability.

Report suspected vulnerabilities by contacting:

**nyaonyao0725@gmail.com**

Please include:

- A description of the issue.
- Steps to reproduce, if available.
- The affected version or commit.
- Any suggested mitigation.

We will review reports as soon as possible and coordinate a fix when needed.
